# Cloudly

Музыкальный плеер для Android (Jetpack Compose). Тёмное дымчатое стекло, зерно, динамическая палитра из обложки, пружинная анимация.

Сейчас в репозитории только дизайн, кода приложения ещё нет.

| Что | Где |
|---|---|
| Интерактивный прототип (открыть в браузере) | [`prototype/index.html`](prototype/index.html) |
| Дизайн-спека: цвет, типографика, стекло, зерно, движение, экраны, источники музыки | [`docs/DESIGN.md`](docs/DESIGN.md) |
